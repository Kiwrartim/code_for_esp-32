# code_for_esp-32
# ESP32 Learning & Experiments

A collection of beginner-to-intermediate ESP32 microcontroller projects, hardware experiments, and code snippets developed in Visual Studio Code. 

## About This Repository
This repository serves as a personal sandbox and learning log as I explore embedded systems, GPIO control, sensors, and wireless features on the ESP32 platform. Everything here is kept simple, modular, and open for anyone else who is also learning.

## Development Environment
All projects in this repository are built and flashed using **Visual Studio Code**:
* **Microcontroller:** ESP32 Development Board
* **IDE:** [Visual Studio Code](https://visualstudio.com)
* **Framework / Extension:** PlatformIO / Arduino
* **Language:** C / C++

## How to Use These Projects
1. **Clone the repository:**
   ```bash
   git clone https://github.com[your-username]/[your-repo-name].git
   ```
2. **Open in VS Code:** Open the specific project folder you want to run inside Visual Studio Code.
3. **Connect your ESP32:** Plug your ESP32 board into your computer via USB and check that your serial drivers (such as CP210x or CH340) are installed.
4. **Build & Upload:**
   * **PlatformIO:** Click the **Upload** (right-arrow) icon on the bottom status bar.
